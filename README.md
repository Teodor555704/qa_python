# qa_python
# Тестирование приложения BooksCollector

## Описание проекта

Проект представляет собой набор юнит-тестов для класса BooksCollector, который управляет коллекцией книг, их жанрами и избранными произведениями.

## Основные компоненты

* **BooksCollector** — основной класс приложения
* **tests.py** — файл с тестовым покрытием
* **requirements.txt** — зависимости проекта

## Функциональное покрытие тестами

### Базовые операции

* Создание и инициализация объекта
* Работа со словарем книг
* Управление списком избранного

### Тестирование добавления книг

* Проверка корректности добавления
* Валидация длины названия
* Обработка дубликатов
* Работа с пустыми значениями

### Работа с жанрами

* Назначение жанров книгам
* Получение жанров
* Фильтрация по жанрам
* Проверка возрастных ограничений

### Управление избранным

* Добавление в избранное
* Удаление из избранного
* Получение списка избранных
* Защита от дублирования

### Дополнительные проверки

* Обработка несуществующих книг
* Валидация названий книг
* Тестирование всех доступных жанров
* Проверка книг без жанра
